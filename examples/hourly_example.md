# Hourly update — one Telegram message per item

Each message is a short heading (one line, no cut-off) + Read More link.

**Message 1:**
```
**Is the Real Consensus at Hong Kong 2026 That Crypto Is Finished?**

[Read More](https://wublock.substack.com/p/is-the-real-consensus-at-hong-kong)
```

**Message 2:**
```
**Digital asset outflows extend to 4th week amid US weakness, totalling US$173m**

[Read More](https://researchblog.coinshares.com/volume-273-digital-asset-fund-flows-weekly-report)
```

**Message 3:**
```
**Cathie Wood Buys COIN After 16% Jump**

[Read More](https://finnhub.io/api/news?id=example)
```

Long or messy headlines (e.g. raw tweets) are flattened to one line and truncated at a word boundary (~96 chars) so nothing is cut off mid-word.
